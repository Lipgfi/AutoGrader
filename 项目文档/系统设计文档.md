## 一、系统架构设计

### 1.1 整体架构

系统采用前后端分离架构，前端使用Vue 3 + TypeScript + Element Plus，后端采用微服务架构（多个后端服务B-1、B-2、B-3、B-4）。

#### 权限控制

```typescript
// 路由守卫
router.beforeEach((to, _from, next) => {
  // 设置页面标题
  document.title = to.meta.title
    ? `${to.meta.title} - AutoGrader`
    : 'AutoGrader'

  // 权限验证
  const userStore = useUserStore()
  const publicPages = ['/login', '/register']
  const isPublicPage = publicPages.includes(to.path)

  if (!isPublicPage && !userStore.isLoggedIn) {
    next('/login')
    return
  }

  // 角色权限验证
  const requiredRole = to.meta.role
  if (requiredRole && userStore.role !== requiredRole) {
    next('/')
    return
  }

  next()
})
```

### 2.3 API服务模块设计

#### 基础API配置

```typescript
// services/api.ts
const api = axios.create({
  baseURL: '/api',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json' }
})

// 请求拦截器：添加Token
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：统一处理
api.interceptors.response.use(response => {
  const { code, message, data } = response.data
  if (code === 200) return data
  else {
    ElMessage.error(message || '请求失败')
    return Promise.reject(new Error(message))
  }
}, error => {
  ElMessage.error(error.message || '网络错误')
  return Promise.reject(error)
})
```

#### 权限服务

```typescript
// services/permissionService.ts
export const permissionService = {
  // 检查用户权限
  hasPermission(permission: string): boolean {
    const userStore = useUserStore()
    return userStore.permissions.includes(permission)
  },

  // 检查用户角色
  hasRole(role: string): boolean {
    const userStore = useUserStore()
    return userStore.role === role
  },

  // 检查操作权限
  canPerformAction(resource: string, action: string): boolean {
    const userStore = useUserStore()
    const key = `${resource}:${action}`
    return userStore.permissions.includes(key) || userStore.role === 'admin'
  }
}
```

  UPDATE = 'update',
  DELETE = 'delete',
  VIEW = 'view',

  GRADE = 'grade'

// 操作日志Composable
