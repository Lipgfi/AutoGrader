## 历史问题修复状态

### 1. Mock 模式残留
- **问题**: `vite-plugin-mock` 插件拦截登录请求，返回 Mock 数据而非调用真实后端

- **问题**: `Layout.vue` 使用 `<slot></slot>` 而非 `<router-view />`，导致嵌套路由子页面无法渲染
- **状态**: ✅ 已修复 - 替换为 `<router-view />`

### 3. 登录角色选择器无后端校验
- **问题**: 登录页有学生/教师/管理员身份选择器，但后端不验证前端传入的 `role` 字段
- **状态**: ✅ 已修复 - `Login.vue:335-339` 添加后端角色校验逻辑

### 4. 验证码前端自生成
- **问题**: 登录页验证码由前端本地生成并校验，安全机制形同虚设
- **状态**: ✅ 已修复 - `Login.vue:160-176` 优先从后端获取，本地生成仅作降级方案

### 5. 各页面硬编码 Mock 数据
- **问题**: 课程列表、作业列表、成绩、题库、用户管理、Dashboard 等页面均内嵌假数据
- **状态**: ⚠️ 部分修复 - 核心页面已改为 API 调用，Dashboard 等页面保留部分假数据

### 6. 前后端字段命名不一致

## 联调注意事项

### B3 接口调用方式
```typescript
// 评测请求格式
{
  "question_id": "Q02",
  "submitted_code": "ssh user01@127.0.0.1\nexit",
  "submission_id": "demo-submission",
  "language": "shell"
}

// 评测返回格式
{
  "question_id": "Q02",
  "submission_id": "demo-submission",
  "overall_score": 100,
  "passed_count": 1,
  "total_count": 1,
  "overall_comment": "...",
  "static_issues": [],
  "case_results": [...]
}
```

### B3 支持的题目类型
- `command`: 命令行题目
- `file`: 文件读取/处理题目
- `script`: Shell 脚本题目
- `api`: Python 函数调用题目

### CORS 问题解决方案
所有跨域请求通过 Vite 代理转发，前端使用相对路径：
```typescript
// 正确方式
const response = await evaluateSubmission({...})  // 使用 /api/v1/b3 代理

// 错误方式（直接跨域，会被浏览器拦截）
axios.get('http://localhost:8003/api/v1/b3/questions')
```
